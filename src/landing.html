Under the hood

Built like the receipts matter — because they do.

🧾

Every paid answer carries its evidence

An evidence_bundle rides on every response: hash of the canonical request, hash of the response, the pinned block, the mode. The recompute recipe is documented, byte for byte.

🔁

Settled but reply lost? You replay free.

Send x-idempotency-key once per operation: within 10 minutes a retry returns the same verdict with no second charge. Double-keyed under the request content too — a fresh key still replays.

⏱️

Window expired? Typed, not silent.

After the window closes, a retry re-measures with the paywall re-armed and comes back flagged recovery.remeasured with the previous verdict's hash — an agent can branch on it, never guess.

🛡️

Spend caps with a stated boundary

The MCP bridge enforces a hard per-call ceiling and an optional per-day ledger. Stated plainly: the caps live in the signer process and don't travel to delegated wallets.
