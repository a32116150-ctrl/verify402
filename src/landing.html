Questions,
answered.

Does PASS mean the transaction is safe?

No. PASS means the listed checks passed at that block. Read notChecked for what the gate did not verify, including counterparty reputation, sanctions, settlement, and off-chain promises. A PASS is a measurement, not a guarantee.

What does the gate return besides the verdict?

For transactions it also returns advice: a plain-language explanation, a preview of what leaves and enters the wallet, fixes with suggested values for anything flagged, who the transaction involves, the dollars at risk, and the paid check that fits next.

Can I set a spending risk limit for my agent?

Yes. Add maxRiskUsd to the policy. A transaction that puts more than that many dollars at risk is BLOCK, and one whose risk cannot be priced is CAUTION, so the agent asks its owner first. It limits what the agent signs; it is not insurance.

Does verify402 refund losses?

No. verify402 warns before a signature; it never holds, moves, insures or refunds funds, and a signed transaction cannot be undone.

What does it cost?

The preflight gate and the live findings are free. Individual checks cost $0.02-$0.05 each; the /assure bundle costs $0.10. Paid calls settle in USDC on Base mainnet.

Do I need a wallet?

Not for the free gate or the browser demo. No account and no API key. A wallet is only needed if you choose to call the paid checks; the MCP bridge caps what it can authorize.

Does it sign or send a trade?

No. verify402 returns a verdict and a receipt. The executor and its signer decide what to do. The MCP bridge signs the x402 payment only; it never signs or sends a trade.

Can I use it with my own agent?

Yes. Use the free MCP server for preflight_gate, or call the HTTP endpoint from any runtime. The skill and references cover the exact payment and transaction payloads.

Is this mainnet?

The analysis reads mainnet chain data. This instance settles real USDC on Base mainnet and Solana mainnet through the Coinbase CDP facilitator. No result is a profit forecast.
