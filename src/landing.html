One call
before the signature.

The gate is intentionally boring: build the exact intent, check it at a fresh block, keep the receipt. If the verdict is BLOCK, the executor stops.

Intent

Build the exact payment request or transaction. No hand-waving about what the agent thinks it is signing.

Gate

PASS, CAUTION, or BLOCK at a fresh block, with typed reasons and a list of what was not checked.

Receipt

Verify the short-lived receipt against the intent. Then sign, or stop. The choice stays with the executor.

Free. No account, API key, or wallet. The paid checks are optional.

Questions,
answered.

Does PASS mean the transaction is safe?

No. PASS means the listed checks passed at that block. Read notChecked for what the gate did not verify, including counterparty reputation, sanctions, settlement, and off-chain promises. A PASS is a measurement, not a guarantee.

What does it cost?

The preflight gate and the live findings are free. The five deep checks are fixed price, from $0.03 to $0.10 per call. Paid calls use testnet USDC in the public demo; mainnet settlement is not the demo default.

Do I need a wallet?

Not for the free gate or the browser demo. No account and no API key. A wallet is only needed if you choose to call the paid checks; the MCP bridge caps what it can authorize.

Does it sign or send a trade?

No. verify402 returns a verdict and a receipt. The executor and its signer decide what to do. The MCP bridge signs the x402 payment only; it never signs or sends a trade.

Can I use it with my own agent?

Yes. Use the free MCP server for preflight_gate, or call the HTTP endpoint from any runtime. The skill and references cover the exact payment and transaction payloads.

Is this mainnet?

The analysis reads mainnet chain data. Public demo payments are Base Sepolia testnet USDC. No mainnet payment service is being offered here, and no result is a profit forecast.
