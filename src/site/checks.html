Before any of these: the free preflight gate

/preflight checks the transaction or the x402 payment request itself — PASS / CAUTION / BLOCK, a short-lived receipt, and an honest notChecked list. It is free because it has to run before every signature. These six checks are the deep measurements behind it. Use the gate from an agent with the MCP server.

/verify — $0.05 · is this arbitrage real?

Takes a claimed cross-venue opportunity and measures it at a pinned block: Uniswap's own QuoterV2 on one side, each router's own math on the other, flash-loan premium and gas subtracted before any verdict is printed.

You get

Three honest states

edge — profit survives measured costs. no_edge — it doesn't exist at this block. no_edge_costs_ate_it — a gross spread existed; costs ate it. The verdict names which.

Receipt

Recomputable by anyone

request hash, response hash, pinned block, and the numbers behind the verdict — enough for a third party to redo the check without trusting us.

Request shape 
POST /verify
{ "chainId": 1, "target": "WETH", "base": "USDC", "size": 10000 }

/safety — $0.02 · can this token be sold?

Token safety check for AI agents before they swap: quote-based sellability, round-trip cost, TRUST / CAUTION / AVOID. $0.02 per call, free pre-signing gate included. It does not execute a transfer; transfer restrictions stay in notChecked, so it is not a honeypot proof. Contract facts, market liquidity, scam signals, a USD-sized sell QUOTED through the configured venues' own routers, round-trip cost at your intended size, and phantom-price detection — then TRUST, CAUTION or AVOID, with the evidence named. It does not execute a transfer, and transfer restrictions are listed in notChecked.

Request shape 
POST /safety
{ "chainId": 1, "tokenAddress": "0x95aD…", "intendedUsd": 500 }

Most calls land on CAUTION or AVOID. A gate that only said yes would be a marketing page, not a gate.

/route — $0.03 · what would the chain pay?

Best execution route for a swap, plus every quoted venue at your size. Useful when a UI shows one price and the chain would pay another.

Request shape 
POST /route
{ "chainId": 1, "tokenIn": "USDC", "tokenOut": "WETH", "amountIn": "1000000000" }

/quotecheck — $0.05 · is this quote honest?

Someone — a broker, a bot, another agent — gave you a number. This re-measures it at a pinned block and answers: fair, overpaying, or too good to be true.

Request shape 
POST /quotecheck
{ "chainId": 1, "tokenIn": "USDC", "tokenOut": "WETH", "amountIn": "1000000000", "quotedOut": "326000000000000000", "venueClaimed": "some-router.example" }

/depth — $0.05 · how big can this trade be?

Position sizing: a capacity ladder across USD sizes, with the realizable impact and round-trip cost at each rung. Pool-reserve headlines tell an agent nothing about the block it will actually trade in.

Request shape 
POST /depth
{ "tokenAddress": "WETH", "baseSymbol": "USDC", "sizesUsd": [100, 1000, 10000, 100000] }

/assure — $0.10 · one evidence bundle

Runs whichever of those checks you supply — safety, route, quotecheck, or depth — at one pinned block and returns one evidence record with a recomputable sha256. Accepted only when the checks you ask for cost at least $0.10 separately (parts total $0.12), so the bundle costs less than buying them one by one. Unsupplied checks are reported as notChecked, never guessed.

POST /assure
{ "chainId": 1, "safety": { "tokenAddress": "WETH", "intendedUsd": 500 }, "route": { "tokenIn": "USDC", "tokenOut": "WETH", "amountIn": "1000000" }, "quotecheck": { "tokenIn": "USDC", "tokenOut": "WETH", "amountIn": "1000000", "quotedOut": "326000000000000000" }, "depth": { "tokenAddress": "WETH", "sizesUsd": [100, 1000] } }

Fixed, exact, on the rail.

Caps and safety
