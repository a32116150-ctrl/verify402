Read the verdict

Three states, no marketing.

A verdict is a measurement at one block, not a promise about the next one. These names exist so an agent can branch on them instead of squinting at a number.

Edge

It survives costs

A real spread remained after flash-loan premium, gas, and the round trip. Rare on mainstream pairs, and the only state that is a positive answer.

No edge

It doesn't exist

No spread at this block. Most "opportunities" that agents are sold land here — which is exactly why the verdict is published this bluntly.

No edge — costs ate it

It existed; costs won

A gross spread was there on paper, but the measured costs were larger. The distinction matters: one is a fake opportunity, the other is a real one you still shouldn't take.

Recompute, don't trust

The receipt is the product.

Every paid response carries an evidence bundle: the hash of the canonical request, the hash of the actual response body, and the pinned block. Anyone can fetch the block's quotes and redo the arithmetic.

The free route returns the same shape of data, minus the paid detail. Use it to check that this service is willing to answer negatively before you ever pay it.

curl https://verify402.onrender.com/findings

Machine clients get the same JSON at /findings. Paid detail per pair: /verify.

What this page does not mean

No verdict here is financial advice, and none of it is a promise that a trade is safe or profitable. A finding is a quote about one block — the chain moves, and so do the numbers. The paid checks exist because size, token, and venue change the answer.
